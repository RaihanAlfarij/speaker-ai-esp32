# 0005 — Format konten: daily build vlog + tutorial dari rakitan kedua

- **Tanggal:** 2026-11-17
- **Status:** Diterima

## Konteks
Ingin membuat konten dari proses build sekaligus video tutorial DIY di YouTube. Merekam tutorial sambil membangun pertama kali akan memecah fokus (setup kamera, ganti angle), memperlambat progres, dan hasilnya penuh jalan buntu. Sebaliknya, kalau tidak merekam sama sekali, tidak ada stok konten.

## Keputusan
1. **Daily build vlog ("Hari ke-N", per sesi kerja)** — direkam minim usaha (2 HP: atas tetap + close-up), diposting apa adanya ke IG Reels, Shorts, TikTok.
2. **Carousel milestone** — 12 topik ilmu/rangkuman ke IG feed & Threads saat milestone tercapai.
3. **Tutorial YouTube** — dibuat setelah v1 jadi, dari **rakitan kedua** yang mulus (fase 7).

## Konsekuensi
- Fokus tetap pada build; konten tetap mengalir.
- Rakitan kedua menguji bahwa panduan bisa diikuti orang lain (bekal open-source & kit) dan menghasilkan unit kedua.
- Perlu disiplin: tekan rekam tiap sesi, catat devlog, cek privasi sebelum posting.
